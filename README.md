# VECTOR CRAWLER

Three.jsで構築した、円筒トンネル全表面を走行するオリジナル3Dアクションゲームです。
外部3Dモデル・既存作品の素材・既存楽曲は使用していません。

## 起動

Node.js 20以降を使用してください。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開き、`START INCURSION`を押します。

本番用ビルド：

```bash
npm run build
npm run preview
```

## GitHub Pages公開

このリポジトリには`.github/workflows/deploy-pages.yml`を同梱しています。
`main`ブランチへpushすると、GitHub ActionsがビルドしてPagesへ公開します。

初回だけGitHubリポジトリの `Settings → Pages → Build and deployment` で
`Source: GitHub Actions` を選択してください。

公開URLは通常、次の形式です。

`https://<GitHubユーザー名>.github.io/<リポジトリ名>/`

Viteは相対アセットパスでビルドするため、リポジトリ名が変わっても動作します。

## 操作

### PC

- `W / S`: 前進・後退
- `A / D`: 円筒内壁を左右へ走行
- マウス: 照準
- 左クリック: 射撃
- 右クリック長押し: ロックオン
- `Shift`: 高速スライド
- `Space`: 壁面から一時離脱
- `Q / E`: 左右ロール移動
- `F`: スキャン
- `Escape`: ポーズ

### タッチ

- 左側ドラッグ: 移動
- 右側ドラッグ: 照準
- 右下ボタン: 射撃・ロック・スライド・ジャンプ・スキャン

画面のスクロール、ズーム、長押し選択は無効化されています。

## 実装済み

- 円筒座標による内壁360度走行
- ステージ1ボス撃破後に切り替わる立体建築物ステージ
- Raycastによる建築物の屋上・壁・下面への任意表面吸着
- 床・壁・天井を区別しない連続吸着
- クォータニオン補間による四脚メカ姿勢
- 独立補間・壁外クランプ付き三人称カメラ
- 簡易四脚歩行とスライド変形
- 弾丸オブジェクトプール
- 砲台、浮遊ドローン、大型防衛装置
- 射撃、被弾、耐久値、エネルギー、ロックオン
- スキャンパルスとボス弱点表示
- ワイヤーフレーム、ブルーム、残像、走査線、ノイズ、被弾歪み
- 線分パーティクル
- タイトル、HUD、ポーズ、クリア、ゲームオーバー、リトライ
- スコア、撃破数、命中率、制限時間
- Web Audio APIによる生成音、音量、ミュート
- PC/タッチ自動判定、レスポンシブUI
- 低性能モード、ピクセル比上限、非表示時自動ポーズ

## 既知の問題

- 基本ジオメトリ主体のMVPのため、障害物は主に視覚的な回避対象です。
- 端末内蔵ブラウザによっては、Web Audio開始にSTARTボタン操作が必要です。
- 低性能GPUでは残像を有効にすると負荷が高いため、低性能モードでは無効になります。
